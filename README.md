# Polygon Fusion Planner

Интерактивно Next.js приложение, което намира най-късите връзки между множество несвързани полигони, изгражда минимално свързващо дърво и генерира обединена многоъгълна геометрия. UI-то предлага визуализация, контрол на дебелината на мостовете и автоматично извеждане на финалната фигура във WKT формат.

## ✨ Основни възможности

- Анализ на набор от полигони (JSON вход) и извличане на минимални разстояния между тях.
- Генериране на правоъгълни „мостове“ с избрана ширина по най-късите сегменти.
- Използване на minimum spanning tree за оптимално свързване на всички полигони.
- Boolean union чрез `polygon-clipping`, за да се получи крайна многоъгълна фигура.
- SVG визуализация на входните полигони, мостовете и резултата, плюс автоматичен WKT изход.


## 🧠 Алгоритмична логика

1. **Изчисляване на дистанции** – за всяка двойка полигони се намира най-късият сегмент (точка до точка) чрез анализ на всички ръбове.
2. **Минимално свързващо дърво** – прилага се Prim, за да се изберат най-късите връзки, които свързват всички полигони.
3. **Геометрични мостове** – за всеки сегмент се създава правоъгълник с избрана ширина, ориентиран по съответния вектор.
4. **Обединение** – оригиналните полигони и мостовете се подават на `polygon-clipping.union`, което връща крайна свързана многоъгълна геометрия.

## 🛠 Полезни насоки

- Във входния JSON всеки полигон е масив от точки `{ "x": number, "y": number }`.
- За по-сложни топологии просто добавете още полигони – приложението ще ги свърже оптимално.
- Ширината на мостовете определя размера на коридорите между полигоните.
